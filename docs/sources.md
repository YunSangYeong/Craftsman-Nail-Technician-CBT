# 시험 규칙·출처·검수 기록

조사일: 2026-10-27 (한국 시간). 대상: 미용사(네일).

## 공식 시험 규칙 확인 상태: 미확인

확인 대상으로 삼은 공식 종목 페이지:
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7957

실제 요청 결과: `curl: (56) CONNECT tunnel failed, response 403`, HTTP 응답 코드 `000`.
프록시 연결 단계에서 차단되어 본문·첨부 출제기준을 읽지 못했다.
URL은 확인 대상이며 읽은 근거가 아니다. 시험 과목 명칭, 출제기준 적용 기간,
공식 과목별 출제 수/선정 방식, 시간, 채점·합격·과락 규칙 및 실기 규칙을
공식 검증 완료로 표시하지 않는다. 공식 원문 문항·정답과 재배포 조건도 미확인이다.
민간 문제은행을 복사하지 않았고 공식 로고도 사용하지 않았다.

현재 `src/qualification.ts`에 설정한 **학습용 잠정 규칙**:
60문항, 60분, 4지선다, 문항당 동일 비중(정답 수/전체 수×100), 60점 이상 합격,
과목 과락 없음, 미응답 오답. 점수는 소수 첫째 자리 표시이나 합격은 반올림 전 비율로 판단한다.
이는 미용사(네일) 공식 규칙을 대조한 결과가 아니다. 전기기능사의 규칙이 네일에도
공식적으로 동일하다고 단정하지 않는다. 정확한 공식 기준 확인이 남아 있다.

공식 과목 분포를 꾸며내지 않기 위해 시험 추출 과목은 `네일미용 통합` 하나로 두었다.
아래 다섯 영역은 자체 학습 분류이며 공식 시험 과목/배분이라는 뜻이 아니다.
전체 내부 검토 문항에서 ID 중복 없이 무작위로 60개 추출한다.
수치 변형은 family별 우선 한 문항만 뽑으며 전체 314개 그룹(개념·상황 300문항+수치 문형 14개)에서
그룹을 먼저 무작위 선택한다. 따라서 700개 변형이 곧 시험의 70%를 차지하는 것은 아니다.
기본 은행은 그룹이 충분해 같은 수치 문형의 중복 출제가 없다. 로컬 은행 등에서 그룹이 부족하면
서로 다른 ID로 보충하는 기준 앱 정책은 유지한다. 랜덤 학습은 전체 1,000개의 개별 문항을 순회한다.

## 실제 문제은행

| 자체 학습 영역 | 개념·상황 | 수치 조건 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 네일 개론 | 60 | 100 | 160 |
| 피부·손발톱 | 60 | 0 | 60 |
| 위생·안전 | 60 | 100 | 160 |
| 화장품·재료 | 60 | 400 | 460 |
| 네일 기술 | 60 | 100 | 160 |
| 합계 | 300 | 700 | 1,000 |

원문 기출 0 / 복원 0 / 자체 제작 1,000 / 개념·상황형 300 / 수치 조건 변형 700.
기본 JSON의 검증 대기 0, ID·정규화 본문/보기 중복 0, 등록 1,000, 목표 대비 부족 0.
외부 전문가 검수 완료 문항은 0이다. 사용자 로컬 등록분은 위 수량에서 제외한다.
기존 `NAIL-001`~`NAIL-060`의 ID·본문·보기·답안·해설·메타데이터를 그대로 보존했다.

### 수치 변형 14문형 × 50조건

| 문형 ID | 계산 목표 | 문항 수 |
| --- | --- | ---: |
| soluteMass | 질량 백분율에서 성분 질량 | 50 |
| massPercent | 성분 질량에서 질량 백분율 | 50 |
| solventMass | 두 성분 혼합물에서 용매 질량 | 50 |
| dilutionStock | 농도·최종 부피에서 원액 부피 | 50 |
| dilutionWater | 원액과 목표 농도에서 추가 물 부피 | 50 |
| dilutionFinal | 원액과 목표 농도에서 최종 부피 | 50 |
| mixturePercent | 동일 성분 용액 혼합의 가중 평균 농도 | 50 |
| componentRatio | 가상의 질량비 배분 | 50 |
| trayArea | 직사각형 트레이 윗면의 총면적 | 50 |
| containerVolume | 여러 용기에 배분할 총부피 | 50 |
| completeUses | 남길 양을 제외한 완전한 사용 횟수 | 50 |

| materialCost | 가상 제품의 1회분 재료비 | 50 |

14개는 **문제 문형 수**다. 희석 세 문형처럼 같은 원리에서 미지수만 달라지는 경우도 있어
14개가 서로 완전히 다른 공식이나 독립 개념이라는 뜻은 아니다. 700개는 각 문형의 숫자 조건 변형이며
기출 수나 독립 개념 수로 세지 않는다. 총 1,000개 모두 다른 전문 지식이라는 뜻이 아니다.
재료비·재고·작업 일정은 네일 서비스의 보조 실습이지 공식 필기 출제 비중을 입증한 내용이 아니다.
랜덤 은행에서 계산 연습 비중이 높으므로 공식 시험 대비를 이 은행만으로 대체하지 않는다.

농도 문항은 가상의 단일 성분과 성분량 보존을 가정한다. 부피 단순 합산을 쓰는 경우 그 가정을 밝히며,
실제 제품의 소독액 농도·접촉 시간·아크릴 배합비·젤 경화 시간으로 쓰지 않는다.
제품의 실제 사용은 제조사 표시·안전 지침과 적용 규정을 따른다.
계산 결과는 문항에 지정한 단위로 답한다. 소수 둘째 자리 또는 원 단위의 일반 반올림,
완전한 사용 횟수의 버림을 구분하고 조건·식·대입·결과를 해설에 기록했다.

### 검토 범위

`reviewed`는 **AI 내부 검토** 상태다. 일반 지식을 바탕으로 새로 작성한 개념·상황 원고의
질문·단일 정답·보기 구별·해설을 검토했다. 특정 교재나 읽지 못한 Q-Net 자료를 정답 근거로
인용하지 않았다. 모든 연도·회차는 null이며 저장소 URL은 작성 위치로서 외부 정답 증빙이 아니다.
전문가의 내용 타당성 검수와 공식 출제기준 대조는 미완료다.

ID, NFKC 정규화 본문과 보기 순서를 무시한 중복, 보기의 단위·수치상 동치 여부를 검사했다.
개념·상황형 300개에서 문장 유사도 0.72 초과 후보 19쌍을 확인했으며, 공통 문장틀을 사용하지만
대상 개념·정답이 달라 유지했다. 후보와 판단은 `bank-audit.json`에 남겼다. 같은 안전 원칙을
다른 상황에 적용하는 문항이 있어 이를 모두 독립 개념으로 부르지 않는다. 이 검사는
전문가 의미 검수나 모든 잠재적 의미 중복의 부재를 보장하는 것은 아니다.
수치 변형의 동일 문형은 의도된 것으로 family로 묶어 별도 집계했다.

Python의 Fraction/Decimal 생성과 별개의 JavaScript 대수식으로 700개 전부 재계산하고
정답 번호·단위·반올림·보기의 유일 정답을 검사했다. 수치 검산은 외부 정답 자료 대조나
개념 해설의 전문가 검수와 구별한다. 1,000문항 수량은 충족했지만 공식 시험 재현이나
전문가 검수가 완료됐다고 주장하지 않는다.

## 재생성과 권리

`scripts/author-bank.py`는 최초 60개 원고를 유지하고 `scripts/manuscripts/`의 추가 240개 원고와
`scripts/expand_bank.py`의 결정적인 700개 숫자 변형을 합쳐 기본 JSON을 만든다.
외부 생성 서비스나 비결정적 난수는 사용하지 않는다. 같은 실행은 같은 JSON을 만들며
`--check` 옵션은 파일 변경 없이 현재 JSON과의 일치를 검사한다.
새 ID는 개념 `NAIL-CON-001`~`NAIL-CON-240`, 계산 `NAIL-CALC-01-001` 등의 체계다.
기존 풀이 기록이 참조하는 최초 60개 ID와 내용을 바꾸지 않는다.

앱 코드는 전기기능사 기준 커밋의 MIT 고지를 보존했다.
자체 제작 네일 문항·원고·양식은 `Craftsman-Nail-Technician-CBT contributors`를 표시하는
CC BY 4.0으로 제공한다. 변경 시 변경 사실과 출처 링크를 표시한다.
공식 기출이나 제3자 문항의 이용 권한을 이 라이선스로 대신하지 않는다.
제3자 자료를 추가할 때는 별도의 원문·정답·회차·이용 조건 확인이 필요하다.
