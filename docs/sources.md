# 시험 규칙·출처·검수 기록

조사일: 2026-10-27 (한국 시간). 대상: 미용사(네일).

## 공식 시험 규칙 확인 상태: 미확인

확인 대상으로 삼은 공식 종목 페이지:
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7957

실제 요청 결과: `curl: (56) CONNECT tunnel failed, response 403`, HTTP 응답 코드 `000`.
프록시 연결 단계에서 차단되어 본문·첨부 출제기준을 읽지 못했다.
URL은 확인 대상이며 읽은 근거가 아니다. 시험 과목 명칭, 출제기준 적용 기간,
공식 과목별 출제 수/선정 방식, 시간, 채점·합격·과락 규칙 및 실기 규칙을
공식 검증 완료로 표시하지 않는다. 공식 원문 문항·정답과 재배포 조건도 미확인이다.
민간 문제은행을 복사하지 않았고 공식 로고도 사용하지 않았다.

현재 `src/qualification.ts`에 설정한 **학습용 잠정 규칙**:
60문항, 60분, 4지선다, 문항당 동일 비중(정답 수/전체 수×100), 60점 이상 합격,
과목 과락 없음, 미응답 오답. 점수는 소수 첫째 자리 표시이나 합격은 반올림 전 비율로 판단한다.
이는 미용사(네일) 공식 규칙을 대조한 결과가 아니다. 전기기능사의 규칙이 네일에도
공식적으로 동일하다고 단정하지 않는다. 정확한 공식 기준 확인이 남아 있다.

공식 과목 분포를 꾸며내지 않기 위해 시험 추출 과목은 `네일미용 통합` 하나로 두었다.
아래 다섯 영역은 자체 학습 분류이며 공식 시험 과목/배분이라는 뜻이 아니다.
전체 검수 문항에서 ID 중복 없이 무작위로 60개 추출한다. 현재 60개이므로 한 회에 전부 나온다.
동일 family 우선 1개, 부족 시 서로 다른 ID로 보충하는 기준 앱 정책을 보존했지만
현재 숫자 변형 family는 없다.

## 실제 문제은행

| 자체 학습 영역 | 자체 제작·내부 검토 |
| --- | ---: |
| 네일 개론 | 12 |
| 피부·손발톱 | 12 |
| 위생·안전 | 12 |
| 화장품·재료 | 12 |
| 네일 기술 | 12 |
| 합계 | 60 |

원문 기출 0 / 복원 0 / 자체 제작 60 / 숫자 조건 변형 0 / 계산형 0 / 개념·상황형 60.
기본 JSON 검증 대기 0, 중복 제외 후 등록 60, 목표 1,000 대비 **940 부족**.
외부 전문가 검수 완료 문항은 0이다. 사용자 로컬 등록 문항은 위 수량에서 제외한다.
1,000문항 표준 충족 또는 공식 시험 대비의 완전성을 주장하지 않는다.

`reviewed`는 **내부 검토** 상태이다. AI 일반 지식을 바탕으로 새로 작성한 원고의
질문·단일 정답·보기 구별·해설 문장을 검토했다. 특정 교재나 읽지 못한 Q-Net 자료를
정답 근거로 인용하지 않았다. ID/정규화 본문 및 순서 독립 보기 중복 검사는 자동화했다.
개념/상황의 의미 검토에서 같은 위생 원칙을 다른 상황에 적용하는 문항이 있으며
60개가 모두 별개의 전문 개념이라는 뜻은 아니다. 전문적인 내용 타당성과 공식 출제기준
매핑은 미완료다. 테스트 통과가 의학적 정확성이나 외부 전문가 검수를 뜻하지 않는다.

의료 진단·치료를 시도하는 문항과 확인되지 않은 법령상 시간·농도·수치 문제는 넣지 않았다.
제품 농도·경화 조건·응급조치는 제품별 표시를 따르게 했다. 모든 자체 제작 문항의
출제 연도와 회차는 `null`이다. 저장소의 `sourceUrl`은 **작성 위치**이며 외부 정답 증빙이 아니다.
이러한 검수 범위에서 다룰 수 있는 60개만 등록했고 1,000개를 맞추기 위한 재문장·수치
변형 대량 생성은 하지 않았다. 나머지는 신뢰할 수 있는 근거 확보와 내용 검토가 필요하다.

## 재생성과 권리

`scripts/author-bank.py`는 고정 원고와 ID를 사용한다. 난수나 외부 생성 서비스가 없으며
동일 실행은 동일 JSON을 만든다. 데이터는 `src/data/questions-main.json`에 분리한다.
숫자 변형 생성 코드는 없으며 코드와 데이터를 재생성해 독립 유형 수를 부풀리지 않는다.

앱 코드는 전기기능사 기준 커밋의 MIT 고지를 보존했다.
네일 자체 제작 문항과 등록 양식은 `Craftsman-Nail-Technician-CBT contributors`를 표시하는
CC BY 4.0으로 제공한다. 변경 시 변경 사실과 출처 링크를 표시한다.
공식 기출이나 제3자 문항의 이용 권한을 이 라이선스로 대신하지 않는다.
제3자 자료를 추가할 때는 별도의 원문·정답·회차·이용 조건 확인이 필요하다.
