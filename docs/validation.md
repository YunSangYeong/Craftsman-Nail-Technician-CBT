브라우저 검사는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`로 실행했다.
첫 30개 구성 실행은 30개 모두 통과했다. 출처·권리·저장 실패 검사를 추가한 32개 실행은
30개 통과, 2개 실패였다. 실패는 앱 오류가 아니라 `.bank-row .explanation` 선택자가
접힌 문항까지 20개를 잡아 발생한 strict mode 오류였다. 이를 열린 문항의 해설로 특정했다.
수정 후 `npx playwright test tests/e2e/app.spec.ts --grep '상단 상시'`로 PC/모바일 2개 모두 통과했다.
따라서 최종 시나리오 32개를 각각 통과 확인했지만 수정 후 32개 전체를 한 번에 재실행했다고
표현하지 않는다. CI는 전체 검사를 실행하도록 준비했으나 원격 CI 자체는 미실행이다.

기능 20개(10 시나리오×PC/모바일)와 메뉴 12개(3 화면 조건×휠/터치×2 브라우저 프로젝트).
PC는 Desktop Chrome 설정, 모바일은 Pixel 7 에뮬레이션이다. 실기기·Safari·Firefox는 미실행.
대시보드 스크린샷은 1440×1000 및 390×844에서 열어 육안 확인했다.

## 기능 범위

- 60문항 추출, 검증 대기 제외, 고유 ID, 과락 없는 잠정 학습 규칙의 35/36개 정답 경계.
- 답안 변경·즉시 저장, 새로고침 후 동일 deadline, 60분 만료 및 재접속 자동 제출·중복 방지.
- 수동 제출 확인·취소, 결과 점수·전체 해설·오답 필터·시험 오답만 재학습.
- 랜덤 한 순회 중복 방지, 즉시 채점·중복 기록 방지·연속 정답, 재학습 정답 시 오답 제거.
- 북마크, 학습 통계, 학습 이어하기, JSON/CSV 등록과 원자적 검증·중복 제거,
  pending 격리, 근거 입력 후 로컬 승인, 초기화 후 기본 은행 보존.
- 두 모드 실제 keydown/keyup Space 이동, 미응답 유지·수정키 보호·길게 누르기 보호,
  네이티브 버튼/폼/대화상자 보호, 본문 포커스와 마지막 문제 자동 제출 방지.
- 학습 기준 선택 메뉴 및 상단 `.criteria-note` 없음, 문제은행에서 검수 한계/출처 공개.
  저장 실패 경고와 손상된 저장 원본 보존.

## 메뉴 입력 검증

390×480, 740×360 가로, 390×480 글자 125% 확대에서 메뉴 애니메이션 완료 후 진행했다.
휠은 Playwright mouse wheel, 터치는 Chromium CDP touchStart/move/end를 실제 입력했다.
입력 결과 sidebar.scrollTop>0과 하단 두 도구의 뷰포트 진입을 확인하고
백업 다운로드와 초기화 확인창 열기/취소를 실제 클릭했다. 반대 입력으로 상단에 돌아와
대시보드 뷰포트 진입·클릭·메뉴 닫힘과 가로 넘침 부재를 검증했다.
스크롤 위치를 코드로 대입하지 않았다. 터치 에뮬레이션을 실기기 검사로 보고하지 않는다.
