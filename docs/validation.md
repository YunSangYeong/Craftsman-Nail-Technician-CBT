## 수치와 내용 검토

기존 60개를 보존하고 240개 개념·상황 원고 및 700개 수치 변형을 추가했다.
다섯 자체 학습 영역의 집계와 14개 문형별 50개 서로 다른 입력 조건을 검사했다.
모든 문항의 구조·보기 4개·정답 번호·자체 제작 유형·연도/회차 null·출처 및 검토 상태를 확인했다.
기본 은행과 사용자 로컬 등록분을 구별한다.

수치 문제 700개는 Python Fraction/Decimal 생성기와 다른 JavaScript 대수식으로 전수 검산했다.
단위, 입력값, 정답 번호, 보기의 수치상 동치 여부, 일반 반올림과 사용 횟수 버림을 확인했다.
초기 검사에서 짧은 개념 해설 22개와 가상 조건 표시가 없던 재고 문형 50개가 실패했다.
해설을 구체적으로 보강하고 가상 재고 연습임을 명시한 뒤 검사 1,720개 전부를 다시 통과했다.
계산식을 맞히기 위해 정답 허용 오차나 검증 조건을 약화하지 않았다.

질문 유사도 후보 19쌍은 공통 문장틀을 사용하지만 서로 다른 대상·정답을 묻는 것으로 내부 검토해 유지했다.
정확한 후보와 판단 및 데이터 해시는 `bank-audit.json`에 기록했다.
700개는 수치 조건 변형이며, 300개 개념·상황 문제 또한 모두 별개의 전문 개념이라는 뜻이 아니다.
AI 내부 내용 검토와 계산 검산은 전문가 검수·공식 기준 대조와 다르며 후자는 여전히 미완료다.

## PC·모바일 34개 브라우저 검사

Desktop Chrome과 Pixel 7 설정의 Chromium 에뮬레이션에서 각 17개씩 통과했다.
실기기·Safari·Firefox는 미실행이다.

- 1,000개 은행 집계, 개념 300/수치 700/14문형 공개, 추가 개념 및 수치 문항 검색,
  전체 JSON 내보내기의 실제 1,000개와 메타데이터 확인.
- 60문항 시험 추출·답안·북마크·재접속·36개 정답 합격·결과 해설·오답 복습.
- 절대 시각 기반 만료 자동 제출·중복 방지·만료 후 응답 차단.
- 랜덤 즉시 채점·통계·오답 해제·세션 복구와 두 모드 Space 이동·포커스·입력 보호.
- JSON/CSV 가져오기·중복 제거·검증 대기·검수 근거 입력·초기화 후 기본 은행 유지.
- 학습 기준 메뉴와 상단 상시 안내 부재·출처 한계 및 권리 공개·실제 저장 실패 경고·손상 원본 보존.
- 메뉴: 390×480, 740×360 가로, 글자 125% 확대에서 휠과 CDP 터치 입력을 각각 실행.
  실제 아래 입력으로 하단 백업/초기화에 접근해 다운로드 및 확인창 열기·취소 후,
  반대 입력으로 상단 대시보드에 돌아와 클릭·메뉴 닫힘·가로 넘침 부재를 확인했다.
  코드로 scrollTop을 설정하지 않았다.

단위 검사에서는 랜덤 순회 1,000개 전체의 ID 중복 방지와 시험의 수치 family 중복 방지도 확인했다.
최초 60개 단계 검증 이력은 `validation-initial.md`에 보관했다. 현재 수량은 이 문서와 감사 JSON을 따른다.
